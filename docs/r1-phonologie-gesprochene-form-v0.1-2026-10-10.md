# Mishkenaz — R1-Phonologie und gesprochene Form v0.1

**Stand:** 2026-10-10  
**Status:** konservatives Rekonstruktionsmodell; kein vollständig kanonisiertes Phoneminventar

## 1. Methodische Grenze

Die heutige Schreibform eines Vektors beweist nicht automatisch seine älteste R1-Lautung.

Insbesondere dürfen moderne Inventarformen wie:

```
Log · Phi · Syn · Mö · Ref · Res
```

nicht ohne unabhängigen Beleg als direkte Evidenz für Proto-/R1-Phoneme verwendet werden.

Daher werden drei Evidenzstufen getrennt:

```
A = artikulatorisch/kanonisch verankert
B = aus stabilen R1-Formen gut gestützter Kandidat
C = offene oder spätere historische Realisierung
```

## 2. Gesicherte artikulatorische Kerne (A)

Aus der Proto-Mishkenaz-Schicht sind mindestens folgende Kontraste belastbar:

| Bereich | Kern | Grundlage |
|---|---|---|
| zentraler Vokal | `ə` | Avi-Schwa als kanonischer Rekonstruktionskern |
| offene Vokalität | `a`-Raum | Ah / Ma / Pa / Sa / Ta |
| gerundete hintere Vokalität | `o`-Raum | Oh / Om |
| hohe vordere Vokalität | `i`-Raum | Il / Bi |
| hohe/hintere Vokalität | `u`-Raum | Ku / Auv-Komponente |
| bilabial nasal | `m` | Ma / Om |
| bilabial oral | `p` | Pa |
| bilabialer Ansatz | `b`-Kandidat | Bi; historisch noch zu prüfen |
| koronaler Verschluss | `t`-Raum | Ta |
| vordere Friktion | `s`-Raum | Sa |
| velarer Verschluss | `k`-Raum | Ku |

Diese Tabelle beschreibt zunächst **Lauträume**, nicht zwingend bereits ein vollständiges Phonemsystem.

## 3. Noch nicht gesicherte Konsonanten

Formen mit `l`, `r`, `v`, `h`, `n`, `g`, `f`, `y/j` oder weiteren Segmenten kommen im heutigen Bestand vor.

Sie können:

- echte R1-Phoneme sein;
- Allophone oder historische Ableitungen sein;
- spätere Galut-Entwicklungen sein;
- moderne Rekonstruktionsschreibungen sein.

Bis eine Herkunftsregel vorliegt, werden sie nicht pauschal in ein kanonisches Proto-Inventar aufgenommen.

## 4. Vokalsystem als minimaler Kandidatenraum

Für R1 ist als Arbeitsraum mindestens plausibel:

```
/a i u o ə/
```

`ə` besitzt dabei eine besondere historische Stellung durch Avi, aber keine grammatische Sondermacht.

Offen bleiben:

- phonemische Länge;
- `e` als eigenständiges Phonem;
- `ö/ø` oder andere gerundete Vorderzungenvokale;
- Diphthonge versus Vokal+Gleitlaut;
- regionale Galut-Erweiterungen.

## 5. Silbenbau: konservative Rekonstruktion

Die ältesten Urgesten favorisieren sehr einfache Strukturen:

```
V
CV
VC
CVC
```

Beispiele der Gestenschicht:

```
Ah   V
Ma   CV
Ku   CV
Om   VC
Il   VC
```

Daraus folgt noch nicht, dass R1 **nur** diese Formen erlaubt.

Als konservatives Arbeitsmodell gilt:

```
R1-Kernsilbe = (C)V(C)
```

mit drei Vorbehalten:

1. komplexe Anlaute sind für den ältesten Kern nicht vorausgesetzt;
2. Kodas sind wahrscheinlich eingeschränkter als Onsets;
3. Komposition kann an Morphemgrenzen komplexere Oberflächen erzeugen.

## 6. Morphemgrenzen

Bei Kombinationen wie:

```
Saha-om
sa-i
Res-Ref-Log
```

müssen drei Ebenen getrennt werden:

```
MORPHEMSTRUKTUR
-> PHONOLOGISCHE VERKNÜPFUNG
-> PHONETISCHE REALISIERUNG
```

Der Bindestrich zeigt in der heutigen Arbeitsorthographie eine Grenze, sagt aber noch nicht, ob Sprecher dort:

- eine Pause;
- einen Glottisverschluss;
- bloßen Silbenkontakt;
- Assimilation;
- Vokalverschmelzung

realisieren.

## 7. Prosodische Gruppe

Die wichtigste bereits begründbare gesprochene Einheit ist nicht die Einzelsilbe, sondern die **prosodische Gruppe**.

Grundstruktur:

```
[PRÄDIKATSGRUPPE] [ROLLENGRUPPE] [ROLLENGRUPPE]
```

Beispiel analytisch:

```
[Saha-om] [bi' Daria] [la' Bach]
```

Arbeitsregel:

> Jede prosodische Gruppe trägt einen Hauptakzent; grammatische Rollenmarker sind schwächer als der lexikalische Kern.

Das legt noch **nicht** fest, auf welcher Silbe eines mehrsilbigen Wortes der lexikalische Akzent liegt.

## 8. Satzrhythmus

R1 ist verbinitial. Der gesprochene Satz sollte diese Architektur hörbar bewahren.

Vorläufig:

```
PREDIKAT > QUELLE > ZIEL
```

als Abfolge von Informationsgruppen, nicht als Behauptung eines festen metrischen Takts.

Ein Sprecher darf Fokus verschieben, ohne die Rollenstruktur zu ändern.

## 9. Operatorbindung in gesprochener Sprache

Für enge Operatorbindung ist noch keine eigene R1-Schreibung kanonisiert.

Prosodisch sind jedoch drei testbare Möglichkeiten plausibel:

### H1 — Akzentdomäne

Ein gehobener Operator bildet eine gemeinsame Akzentdomäne.

### H2 — reduzierte Grenzstärke

Innerhalb des gehobenen Operators ist die Morphemgrenze schwächer als zur nächsten Operation.

### H3 — spätere phonologische Fusion

Häufige Operatoren können diachronisch zu festen Formen verschmelzen.

Diese Hypothesen sind **nicht** gleichwertig mit bereits kanonischen Regeln. Sie werden als Testprogramm geführt.

## 10. Eigennamen in gesprochener R1-Sprache

Eigennamen müssen ihre Referenzierbarkeit behalten.

Grundregel:

> Ein Name wird so wenig wie nötig angepasst und so stark wie nötig, damit er in der jeweiligen Sprachstufe aussprechbar bleibt.

Drei Fälle:

### A. phonotaktisch kompatibler Name

Der Name bleibt weitgehend unverändert.

### B. teilweise inkompatibler Name

Nur problematische Segmente oder Cluster werden repariert.

### C. historisch integrierter Name

Über Generationen kann eine eigene Mishkenaz-Form entstehen.

## 11. Reparaturhierarchie für Fremdnamen

Solange das volle Inventar noch offen ist, wird nur die **Hierarchie** festgelegt, nicht jede konkrete Lautersetzung:

```
1. vorhandenes Segment erhalten
2. nächstes vorhandenes Segment substituieren
3. unerlaubten Cluster syllabifizieren
4. nötigenfalls Epenthese
5. Tilgung nur als letzter Weg
```

Für Epenthese ist `ə` wegen der Avi-Tradition ein starker Kandidat, aber noch **keine kanonische Universalregel**.

## 12. Namen und Rollenmarker

Rollenmarker bilden prosodisch eine Einheit mit der folgenden Referenzphrase:

```
[bi' NAME]
[la' NAME]
```

Der Name behält seinen lexikalischen Hauptakzent; der Rollenmarker ist schwach.

Das unterstützt die Wiedererkennbarkeit von Namen auch in schnellem Sprechen.

## 13. Dinge und Gattungslexeme

Gattungslexeme folgen denselben phonotaktischen Regeln wie andere Inhaltswörter.

Sie erhalten keine besondere „Dinglautung“.

Die semantische Stabilität eines Gegenstands wird durch Referenz und Kontext getragen, nicht durch ein eigenes Nominalphonem.

## 14. Ortsnamen

Ortsnamen können konservativer sein als gewöhnliche Lexeme, besonders bei religiöser, administrativer oder erinnerungskultureller Bedeutung.

Daher kann ein Ortsname historisch phonologische Archaismen bewahren.

Das ist eine diachrone Möglichkeit, keine Pflichtregel.

## 15. Minimaler Akzentstandard für die weitere Arbeit

Bis ein vollständiges Wortakzentsystem rekonstruiert ist, gilt nur:

```
GRAMMATISCHER MARKER < LEXIKALISCHER KERN
NEBENMORPHEM <= STAMM
FOKUS kann prosodischen Hauptakzent verschieben
```

Nicht festgelegt werden:

- immer erste Silbe;
- immer vorletzte Silbe;
- Tonakzent;
- feste Vokallänge als Akzentkorrelat.

## 16. Testkorpus für die nächste Runde

Die Rekonstruktion sollte an verschiedenen Formtypen geprüft werden:

```
Saha-om
wi-Saha-om
Res-Ref-Log-il
bi'sa-i
la'ta-i
bi'Daria
la'Dvārakā
Ma'Ta'U-reso
```

Für jeden Ausdruck sind zu bestimmen:

- Silbengrenzen;
- Haupt- und Nebenakzent;
- Stärke der Morphemgrenzen;
- mögliche Assimilation;
- Pausen-/Intonationsverhalten;
- historische Varianten.

## 17. Kanonstatus

Bereits stark verankert:

- Avi-Schwa `ə` als Rekonstruktionskern;
- artikulatorische Kerne Ma/Pa/Sa/Ku/Ta;
- prosodische Schwäche von Rollenmarkern gegenüber Referenten;
- Trennung von Urgeste, Vektor, Morphem und Wort.

Arbeitsmodell:

- Minimalvokalraum `/a i u o ə/`;
- Kernsilbe `(C)V(C)`;
- prosodische Gruppen;
- Reparaturhierarchie für Fremdnamen.

Noch offen:

- vollständiges Konsonanteninventar;
- exakte Allophone;
- Wortakzent;
- Sandhi;
- feste Epenthese;
- genaue Operatorbindungsprosodie;
- historische Lautwandelregeln R1 -> Galut.
