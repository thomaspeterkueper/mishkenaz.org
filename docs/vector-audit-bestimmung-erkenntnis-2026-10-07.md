# Mishkenaz — V01–V42 Audit zu Modalität, Bestimmung und Erkenntnis

**Stand:** 2026-10-07  
**Status:** Arbeitsaudit; keine Umdeutung des Kanons  
**Grundlage:** aktueller `main`-Kanon plus detailliertes Vektor-Inventar des bereits reviewten, aber noch nicht gemergten Migrationsbranches. Moderne Kürzel werden nicht etymologisch rückgedeutet.

## Ergebnis in Kürze

Das bestehende System enthält bereits erhebliche Bausteine für die neue Architektur. Es gibt jedoch **keinen einzelnen Bestimmungsvektor**. Bestimmung lässt sich derzeit eher als Komposition mehrerer Richtungen lesen.

Besonders relevant sind:

- `La` — Öffnung / Möglichkeitsraum
- `Ta` — Grenze / unterscheidbares Gegenüber
- `Lim` — Schwelle / Grenze als Ort
- `Vol` — Instabilität / Unbeständigkeit
- `Res` — Residuum / verbleibende Spur
- `Ref` — Rückschau / Reflexion
- `Tra` — Weitergabe / Überlieferung
- `Rek` — Rekursion / Rückkopplung
- `Log` — Struktur / bewusstes Konstruieren
- `-val` — Emergenz / neues Erscheinen
- `-reso` — Wechselwirkung
- `-ira` / `-vya` — Anziehung / Distanzierung
- `-kora` — Integration

## Audit nach Oktaven

### I — Physis und erste Wahrnehmung

| ID | Form | Kern | Neue Achse | Bewertung |
|---|---|---|---|---|
| V01 | Sol | Impuls / erster Stoß | Aktualisierung | guter Kandidat für Beginn eines Vollzugs, nicht für Bestimmung selbst |
| V02 | Mira | Welle / Fluss / Bewegung | Vollzug | dynamisch, keine epistemische Funktion |
| V03 | Sa | Bruch / Trennung | Modalität | kann Fortsetzungen verändern oder ausschließen; keine eindeutige Festlegung |
| V04 | Ona | Ganzheit / Vollständigkeit | Formation | beschreibt Zusammenhang, nicht Wahrheit oder Determination |
| V05 | Vya | Richtung / Wille / Absicht | Akteursmodalität | Intention ist nicht Bestimmung; wichtig für Trennung von Absicht und Ergebnis |
| V06 | Saha | Sehen / Wahrnehmen | Erkenntnis | klarer Wahrnehmungsvektor; Beobachtung bleibt von Wahrheit getrennt |

**Befund:** Bereits hier liegt eine wichtige Trennung: `Vya` sagt, was ein Akteur richtet oder will; `Saha` sagt, was wahrgenommen wird; `Sol` kann einen Vollzug anstoßen. Keines davon garantiert den Weltzustand.

**Befund:** `La` ist derzeit der stärkste vorhandene Vektor für **Ermöglichung**. `Pa` könnte für das Spurenproblem wichtiger sein als bisher gedacht: Echo ist eine relationale Antwort, also eine Wirkung, aus der auf einen vorausgehenden Impuls geschlossen werden kann.

**Befund:** `Ta` ist fundamental für Bestimmung, aber nicht Bestimmung selbst: Nur wo Unterschiede bestehen, kann überhaupt entschieden/festgelegt werden, *welcher* Unterschied realisiert ist.

**Befund:** Unsere erste Hypothese zu `Abs` muss verworfen werden. `Lim` ist ebenfalls vorsichtiger zu behandeln: Es ist die **Schwelle**, nicht automatisch die mathematische Einschränkung eines Möglichkeitsraums.

| ID | Form | Kern | Neue Achse | Bewertung |
|---|---|---|---|---|
| V25 | Tra | Transmission / Weitergabe | Provenienz | sehr starker Kandidat für Bericht/Überlieferung |
| V26 | Ska | Skalierung / Muster | Referenz | interessant für AVI-artige Vergleiche über Skalen |
| V27 | Vol | Volatilität / Unbeständigkeit | Modalität | markiert geringe Stabilität / hohe Veränderlichkeit |
| V28 | Res | Residuum / Rest | Spur | stärkster vorhandener Kandidat für materielle/strukturelle Spur |
| V29 | Avi-Sol | Entstehungsmoment | Aktualisierung | Übergang von Potenzial zu Ereignis; teleologische Lesart vermeiden |

**Befund:** Hier liegt wahrscheinlich der größte Fund des Audits: **`Res` kann als Spur-Richtung gelesen werden, ohne Evidenzmarker zu sein.** Das Residuum ist das, was nach einem Geschehen bleibt. Zusammen mit `Ref` und `Tra` entsteht bereits fast eine Erkenntniskette.

### VI — Rückkopplung und Ordnung

| ID | Form | Kern | Neue Achse | Bewertung |
|---|---|---|---|---|

| V33 | Sym | Symmetrie | Struktur | Musterrelation; kein Wahrheitskriterium |
| V34 | Phi | Harmonie / Maß | Passung | darf nicht mit Wahrheit verwechselt werden |
| V35 | Ona-nO | mögliche Rückkehr / Schwelle | Modalität | Möglichkeit, keine notwendige Rückkehr |

**Befund:** `Rek` darf **nicht** allein wegen „Rek-“ zu „Rekonstruktion“ umdefiniert werden. Für Rekonstruktion wäre eine Komposition wie `Ref + Log` oder `Res + Ref + Log` semantisch sauberer: Rest/Spur → Rückschau → strukturierende Modellbildung.

## 1. Vorläufige modale Landkarte

Das Vektorsystem bietet bereits Kandidaten für mehrere unterschiedliche Operationen:

```
Potenzial        -> Avi
Ermöglichung     -> La / Thu
Differenz        -> Ta
Impuls           -> Sol
Wechselwirkung   -> -reso
Anziehung        -> -ira
Distanzierung    -> -vya
Instabilität     -> Vol
Schwelle         -> Lim
Auflösung        -> Sa-h / -h
Integration      -> -kora
Emergenz         -> -val
```

**Bestimmung selbst bleibt eine Lücke.**

Das ist wahrscheinlich gut: Das System zwingt uns nicht, jede Festlegung als elementaren Vektor zu behandeln. Bestimmung könnte ein **resultativer relationaler Zustand** sein, der aus mehreren Operationen entsteht.

## 2. Vorläufige Erkenntniskette aus vorhandenem Material

Besonders vielversprechend ist:

```
Geschehen
  -> Res       (Residuum / das Verbleibende)
  -> Saha      (Wahrnehmung)
  -> Ref       (Rückschau / Reflexion)
  -> Log       (strukturierende Modellbildung)
  -> Tra       (Weitergabe / Bericht)
  -> Behauptung / Wahrheitsprüfung [noch keine eindeutige Vektorform]
```

Das ist keine neue Grammatikregel, sondern eine semantische Rekonstruktionshypothese.

`Pa` kann zusätzlich einen Sonderfall tragen: **Echo/Antwort** als unmittelbar relational hervorgebrachte Spur.

## 3. Referenz und AVI

Für Referenzbildung sind mindestens drei vorhandene Richtungen interessant:

- `Bi`: Quelle/Herkunft
- `Ska`: Skalierung/Muster über Größenordnungen
- `Ref`: Rückbezug/Rückschau

Keine davon bedeutet allein „Bezugssystem“. Daher sollte Referenz zunächst **syntaktisch** modelliert werden, bevor ein neues Morphem entsteht.

## 4. Kontrakosmologie

`-kora` ist Integration. Für Koexistenz ohne Synthese darf es daher gerade nicht automatisch verwendet werden.

Die vorhandene Struktur `Ma'Ta'U` ist wichtiger:
- `Ma`: Bindung
- `Ta`: erhaltene Differenz

Damit existiert bereits ein Kern für **Relation bei erhaltener Verschiedenheit**.

Offen bleibt eine Konstruktion für:
- zwei gleichzeitig gültige lokale Beschreibungen;
- unterschiedliche Referenzrahmen;
- keine Pflicht zur Integration;
- dennoch gemeinsame Wechselwirkung.

Hier ist zunächst Syntax vor Morphologie zu testen.

## 5. Wichtigste Korrekturen gegenüber der ersten Hypothese

1. `Abs` ist **Absorption/Aufnahme**, nicht Ausschluss.
2. `Lim` ist **Schwelle/Grenze als Ort**, nicht bereits Einschränkungsoperator.
3. `Rek` ist **Rekursion**, nicht automatisch Rekonstruktion.
4. `Res` ist als **Residuum/Rest** wesentlich interessanter für Spur und Evidenzarchitektur als zunächst angenommen.
5. `Log` ist der stärkste Kandidat für **Modellbildung/strukturierende Rekonstruktion**.
6. `Tra` bietet bereits eine natürliche Basis für **Provenienz/Überlieferung**.
7. Bestimmung ist im aktuellen Inventar wahrscheinlich **kompositional**, nicht elementar.

## 6. Nächster Test

Als nächstes sollten minimale Beispielsätze gebaut werden, die folgende Kontraste ausdrücken, ohne neue Morpheme zu erfinden:

1. „Ich sah die Spur.“
2. „Aus der Spur rekonstruiere ich den Vorgang.“
3. „Sie berichtet mir ihre Rekonstruktion.“
4. „Die Rekonstruktion ist stimmig für mich, aber möglicherweise falsch.“
5. „Zwei Modelle erklären dieselbe Spur unterschiedlich.“
6. „Eine Möglichkeit wurde eingeschränkt, aber nicht festgelegt.“
7. „Zwei Systeme wirken aufeinander, ohne zu einem System zu verschmelzen.“

Erst wenn bestehende Vektorkompositionen diese Kontraste nicht stabil tragen, entsteht ein begründeter Bedarf für neue Grammatik.
