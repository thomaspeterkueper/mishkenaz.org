# Mishkenaz — Test der Komplement- und Provenienzsyntax

**Stand:** 2026-10-07  
**Status:** Arbeitsmodell / zu validieren  
**Ziel:** Inhalte von Wahrnehmung, Rekonstruktion und Mitteilung ausdrücken, ohne neue Morpheme einzuführen.

## 1. Grundentscheidung

R1 verwendet vorläufig **parataktische Einbettung**:

```
MITTEILUNG — bi'QUELLE — la'ADRESSAT
INHALTSKLAUSEL
```

In der Analyse kann `‖` als Klauselgrenze geschrieben werden. Es ist kein Morphem.

Diese Lösung passt zur verbinitialen, prozesszentrierten Architektur: Eine Behauptung wird nicht als Ding in ein Objektfach gelegt, sondern als eigener Vollzug angeschlossen.

## 2. Rekonstruktion aus Spur

Arbeitsform:

```
Res-Ref-Log-il bi'sa-i la'[Vorgang]
```

Semantische Zerlegung:

- `Res`: Verbleibendes / Residuum / Spur
- `Ref`: Rückschau / Rückbezug
- `Log`: strukturierende Modellbildung
- `-il`: Rekonstruktionsvollzug wird als offen/suchend markiert
- `bi'sa-i`: erkennender Ausgangspunkt
- `la'[Vorgang]`: Gegenstand/Ziel der Rekonstruktion

Die Spur wird damit in den Prädikatskern integriert. Das vermeidet eine zweite konkurrierende `bi'`-Quelle.

## 3. Bericht einer Rekonstruktion

```
Tra-om bi'ku-i la'sa-i
Res-Ref-Log-il bi'ku-i la'[Vorgang]
```

Lesart:

> „Sie gibt es mir weiter: Sie rekonstruiert den Vorgang aus der Spur.“

Die erste Klausel kodiert **Provenienz der Mitteilung**.  
Die zweite kodiert **Inhalt**.

Wichtig:

```
Tra-om != Inhalt ist wahr
Res-Ref-Log-il != Rekonstruktion ist falsch oder ungewiss
```

Die Aspekte bleiben relationale Passungsmarker.

## 4. Eigene Wahrnehmung vs. fremder Bericht

### Eigene Wahrnehmung

```
Saha-om bi'sa-i la'Res
```

„Ich sehe die Spur.“

### Fremder Bericht

```
Tra-om bi'ku-i la'sa-i
Saha-om bi'ku-i la'Res
```

„Sie berichtet mir: Sie sieht die Spur.“

Damit ist die Herkunft der Aussage strukturell erhalten, ohne dass ein Evidentialsuffix nötig wird.

## 5. Bericht über fremde Rekonstruktion

```
Tra-om bi'ku-i la'sa-i
Res-Ref-Log-il bi'ku-i la'[Vorgang]
```

Das Modell erlaubt, dass der aktuelle Sprecher den Inhalt nur weitergibt. Die Resonanzmarkierung der Inhaltsklausel darf nicht automatisch dem aktuellen Sprecher zugeschrieben werden; bei indirekter Wiedergabe ist daher noch zu klären, ob sie die Perspektive der berichteten Person, des aktuellen Sprechers oder beider markiert.

**Offene Frage:** Perspektivindexierung.

## 6. Warum kein neuer Komplementmarker?

Ein neuer Marker wäre derzeit schlecht begründet, weil:

1. R1 bereits stark relationale Rollenmarkierung besitzt;
2. parataktische Komplementierung typologisch plausibel ist;
3. Mitteilung und Inhalt so ontologisch sauber getrennt bleiben;
4. Provenienz nicht mit Wahrheit verwechselt wird;
5. spätere Galut-Schichten aus einer häufigen Klauselgrenze historisch dennoch einen Komplementierer entwickeln könnten.

## 7. Belastungstest

### Test A — direkte Wahrnehmung

**Soll:** „Ich sehe die Spur.“

```
Saha-om bi'sa-i la'Res
```

**Status:** tragfähig, sofern Vektor-Nominalgebrauch bestätigt wird.

### Test B — eigene Rekonstruktion

**Soll:** „Ich rekonstruiere den Vorgang aus der Spur.“

```
Res-Ref-Log-il bi'sa-i la'[Vorgang]
```

**Status:** semantisch stark; Dreifachkomposition und Lexem für „Vorgang“ noch prüfen.

### Test C — fremde Rekonstruktion wird berichtet

**Soll:** „Sie berichtet mir ihre Rekonstruktion.“

```
Tra-om bi'ku-i la'sa-i ‖
Res-Ref-Log-il bi'ku-i la'[Vorgang]
```

**Status:** strukturell lösbar; Perspektivindexierung offen.

### Test D — Bericht einer falschen Behauptung

Die Provenienzsyntax funktioniert, aber `falsch` kann noch nicht ausgedrückt werden.

**Status:** bestätigt, dass Wahrheit/Falschheit als eigener nächster Entwicklungsbereich nötig ist.

## 8. Konsequenz

Komplementierung benötigt derzeit **kein neues Morphem**.

Der verbleibende Entwicklungsbedarf verschiebt sich auf:

1. Perspektivindexierung bei indirekter Rede;
2. nominale/referenzielle Verwendung von Vektoren;
3. Wahrheit, Falschheit, Behauptung und Prüfung;
4. Modalität: Einschränkung ohne vollständige Bestimmung.

Die Komplement-/Provenienzfrage ist damit vorläufig strukturell gelöst, aber noch nicht voll kanonisiert.
