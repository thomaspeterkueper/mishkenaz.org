# Mishkenaz — R1-Aussprachetestkorpus v0.1

**Stand:** 2026-10-23  
**Status:** phonologische Arbeitsanalyse; keine vollständige phonetische Rekonstruktion

## 1. Notation der Analyse

Die folgenden Zeichen gehören zur **Metaanalyse**, nicht zur Mishkenaz-Orthographie:

```
.   = postulierte Silbengrenze
+   = Morphemgrenze
‿   = enge prosodische Anbindung
|   = Grenze einer prosodischen Gruppe
||  = Klauselgrenze
ˈ   = relativer Hauptakzent einer prosodischen Gruppe, nur wenn seine Position begründbar ist
```

Wo die Silbenposition oder der Wortakzent nicht begründet ist, wird **kein** IPA und kein scheinpräziser Akzent erfunden.

## 2. Grenzstärken

Für die weitere Arbeit werden vier Grenzstärken unterschieden:

| Stufe | Funktion | Erwartete gesprochene Wirkung |
|---|---|---|
| G0 | innerhalb einer Silbe | keine Grenze |
| G1 | innerhalb eines phonologischen Wortes | Silbengrenze möglich; kein eigener Gruppenakzent |
| G2 | Morphemgrenze im Prädikats-/Referenzkern | hörbare Struktur, aber keine notwendige Pause |
| G3 | Grenze prosodischer Gruppen | eigener Gruppenakzent; leichte phrasing cue möglich |
| G4 | Klauselgrenze | Intonationsreset und/oder Pause möglich |

Die Stufen beschreiben **relative Bindungsstärke**, keine festen Millisekunden oder obligatorischen Pausen.

## 3. `Saha-om`

### Morphologische Analyse

```
Saha + -om
```

`Saha` ist der Wahrnehmungskern, `-om` der Resonanzaspekt.

### Silbenhypothese

Unter dem konservativen `(C)V(C)`-Modell ist als **B-Kandidat** plausibel:

```
Sa.ha + om
```

also drei Vokalkerne und kein Zwang zur Verschmelzung von `a+o`.

### Prosodie

```
[Saha-om]
```

bildet eine Prädikatsgruppe. `-om` erhält keinen konkurrierenden Gruppenakzent gegen den Stamm.

**Arbeitsentscheidung:** Morphemgrenze G2; keine obligatorische Pause, kein obligatorischer Glottisverschluss, keine bestätigte Vokalverschmelzung.

## 4. `wi-Saha-om`

### Morphologische Analyse

```
wi- + Saha + -om
```

`wi-` ist Negation; es steht außerhalb des Stamms und vor dem Resonanzaspekt.

### Prosodie

```
[wi-Saha-om]
```

Die gesamte Form bildet eine Prädikatsgruppe. Negation ist semantisch wichtig, soll aber nicht automatisch einen eigenen prosodischen Gruppenakzent erhalten.

### Silbenanalyse

Eine Oberflächenfolge wie:

```
wi.Sa.ha.om
```

ist nur **orthographisch-phonotaktischer Kandidat**, weil der Status von `w` im ältesten R1 noch offen ist.

**Arbeitsentscheidung:** `wi-` und `-om` sind G2-Grenzen; der Stamm bleibt prosodischer Kern.

## 5. `Res-Ref-Log-il`

Dieser Testfall liefert einen wichtigen **Negativbefund**.

`Res`, `Ref` und `Log` sind kanonische moderne Inventarformen, aber ihre sichtbaren Konsonanten dürfen nicht als Beleg für die älteste R1-Lautung verwendet werden.

Daher ist zulässig:

```
[Res-Ref-Log-il]
```

als semantische und prosodische **Arbeitsgruppe**.

Nicht zulässig ist derzeit eine behauptete Proto-/R1-Silbifizierung wie:

```
*Res.Ref.Log.il
```

als historisch gesicherte Aussprache.

**Arbeitsentscheidung:** Grenzstruktur analysierbar, segmentale R1-Aussprache offen.

## 6. `bi'sa-i`

### Struktur

```
bi' + sa + -i
```

`bi'` markiert Quelle; `sa-i` ist der singuläre Referent der 1. Person.

Prosodisch:

```
[bi'‿sa-i]
```

`bi'` lehnt sich an die Referenzphrase an; der Rollenmarker erhält keinen stärkeren Akzent als `sa-i`.

### Silbenhypothese

Als B-Kandidat:

```
bi.sa.i
```

`a+i` bleibt zunächst Hiatus über der Morphemgrenze. Ein Gleitlaut oder eine Verschmelzung wird nicht vorausgesetzt.

**Arbeitsentscheidung:** Rolle→Referent = G1/G2 enge Anbindung; `sa+-i` = G2. Kein obligatorischer Grenzverschluss.

## 7. `la'ta-i`

Parallel zu `bi'sa-i`:

```
la' + ta + -i
[la'‿ta-i]
```

Als B-Kandidat:

```
la.ta.i
```

Auch hier bleibt `a+i` zunächst erhalten.

Der Status von `l` in der ältesten Schicht ist noch offen; die Struktur des Rollenmarkers ist kanonisch, seine tiefste Lautgeschichte nicht vollständig geklärt.

## 8. `bi'Daria`

Hier ist **Namensidentität** wichtiger als interne Mishkenaz-Morphologie.

```
[bi'‿Daria]
```

`bi'` ist prosodisch schwach, `Daria` behält seinen eigenen lexikalischen Akzent.

Wir weisen dem Namen **keinen Mishkenaz-Wortakzent** zu, solange seine konkrete Namensvarietät/Aussprache nicht festgelegt ist.

Ebenso wird die Schreibung nicht in Vektoren zerlegt.

```
Daria != Da + Ri + A als Vektorkomposition
```

**Arbeitsentscheidung:** Name als opake phonologische Domäne; Rollenmarker klitisiert/prosodisch angebunden.

## 9. `la'Dvārakā`

`Dvārakā` ist ein besonders nützlicher Stresstest, weil die Oberfläche Merkmale enthält, die das konservative R1-Kernschema nicht voraussetzt: komplexer Anlaut und markierte Vokallänge.

```
[la'‿Dvārakā]
```

Die erste R1-Regel ist deshalb **nicht** automatische Reparatur, sondern Erhaltung der Namensidentität.

Es werden drei historische Register unterschieden:

1. **Zitat-/Kontaktform:** möglichst quellennah;
2. **integrierte Lehnform:** phonotaktisch angepasst;
3. **erblich gewordene Form:** Ergebnis späteren Lautwandels.

Welche konkrete integrierte R1-Form entsteht, bleibt offen, solange das vollständige Inventar fehlt.

**Arbeitsentscheidung:** keine voreilige Epenthese oder Tilgung.

## 10. `Ma'Ta'U-reso`

Dieser Fall verbindet lexikalisierte/historische Form und produktiven Meta-Operator.

Die bestehende Form `Ma'Ta'U` darf nicht allein aus ihrer Interpunktion als allgemeines Muster für Operatorhebung interpretiert werden.

Prosodisch wird vorläufig getestet:

```
[Ma'Ta'U-reso]
```

mit engerer interner Bindung von `Ma'Ta'U` als zwischen dieser Einheit und `-reso`:

```
Ma'Ta'U  <  -reso
```

wobei `<` hier 'enger gebunden als' bedeutet.

Das ist eine **H1/H2-Prosodiehypothese**, noch keine historische Aussprachebehauptung.

## 11. Ergebnis: drei verschiedene Ausspracheklassen

Das Testkorpus zeigt, dass Mishkenaz nicht mit einer einzigen Aussprachelogik auskommt:

### Klasse P — produktive R1-Morphologie

```
Saha-om
wi-Saha-om
sa-i
ta-i
```

Hier dürfen Silben- und Grenzhypothesen aus der R1-Phonologie entwickelt werden.

### Klasse L — lexikalisierte / historisch gebundene Formen

```
Ma'Ta'U
```

Hier muss die überlieferte Einheit als eigene Domäne berücksichtigt werden.

### Klasse N — Namen / Fremdreferenz

```
Daria
Dvārakā
```

Hier hat Referenzidentität Vorrang vor semantischer Zerlegung.

### Klasse M — metasprachliche Inventarlabels

```
Res
Ref
Log
```

Hier darf die moderne Oberfläche nicht rückwärts als R1-Lautbeweis gelesen werden.

## 12. Vorläufige Prosodieregeln R1-v0.1

Aus dem Testkorpus können jetzt erstmals konkrete, aber begrenzte Regeln formuliert werden:

1. **Rollenmarker sind proclitic-like:** Sie bilden mit der folgenden Referenzphrase eine prosodische Einheit und sind akzentuell schwächer.
2. **Aspekte und produktive Affixe sind stammintern gebunden:** keine obligatorische Pause an `-om/-ath/-il`.
3. **Morphemgrenze ist nicht automatisch Silbengrenze:** Silbifizierung folgt der phonologischen Oberfläche.
4. **Hiatus wird vorläufig erhalten:** keine automatische Gleitlautbildung oder Vokaltilgung.
5. **Operatorhebung kann prosodische Bindung verändern:** aber nur als explizit markierte Analysehypothese.
6. **Namen bilden eigene phonologische Domänen:** Rollenmarker dürfen anbinden, der Name wird nicht semantisch zerlegt.
7. **Moderne Vektorlabels sind keine R1-Ausspracheevidenz.**

## 13. Was weiterhin nicht entschieden ist

- exakte Wortakzentposition interner R1-Lexeme;
- phonetische Realisierung des Apostrophs;
- Existenz eines phonemischen Glottisverschlusses;
- konkrete Allophone von `s`, `t`, `k`, `p`, `m`;
- Status von `b`, `l`, `r`, `w/v`, `h`, `n`, `g`, `f`, `j/y`;
- Vokalreduktion in unbetonten Silben;
- Sandhi über G1/G2-Grenzen;
- konkrete Adaptation von `Dvārakā` und anderen Fremdnamen.

Diese Fragen werden erst nach einem größeren R1-Lexem- und Namenskorpus entschieden.
