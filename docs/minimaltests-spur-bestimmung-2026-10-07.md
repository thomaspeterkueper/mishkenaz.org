# Mishkenaz — Minimaltests zu Spur, Rekonstruktion und Bestimmung

**Stand:** 2026-10-07  
**Status:** Testkorpus / nicht-kanonische Rekonstruktionshypothesen  
**Regel:** Es werden keine neuen Morpheme eingeführt. Formen werden nur dort vorgeschlagen, wo vorhandene Vektoren und die dokumentierte R1-Syntax sie plausibel tragen. Unklare Stellen bleiben offen.

## Bewertungsstufen

- **A — tragfähig:** vorhandene Syntax + vorhandene Semantik reichen weitgehend aus.
- **B — plausibel, aber nicht kanonisch:** Komposition ist semantisch nachvollziehbar, ihre grammatische Produktivität ist noch nicht vollständig dokumentiert.
- **C — Lücke:** die gewünschte Unterscheidung lässt sich derzeit nicht präzise ausdrücken, ohne neue Syntax, Lexik oder Morphologie zu erfinden.

## 1. „Ich sah die Spur.“

### Kandidat
```
Saha-om bi'sa-i la'Res
```

### Lesart
„Von mir geht ein Sehen auf das Residuum / die verbleibende Spur.“

### Bewertung
**B**

`Saha` ist Wahrnehmung, `Res` Residuum/Rest. Die Rollenstruktur trägt den Satz. Offen ist jedoch, ob ein nackter Vektorname wie `Res` in R1 bereits regulär als referenzielles Nomen verwendet werden darf.

**Ergebnis:** semantisch fast vollständig vorhanden; Nominalisierungsregel prüfen.

---

## 2. „Aus der Spur rekonstruiere ich den Vorgang.“

Eine direkte Form mit `Rek` wäre irreführend, weil `Rek` Rekursion und nicht Rekonstruktion bedeutet.

### Kandidat als semantische Komposition
```
Ref-Log-il bi'Res la'[VORGANG]
```

### Lesart
„Vom Residuum her richte ich rückschauend eine Struktur auf den Vorgang.“

### Bewertung
**C/B**

`Ref + Log` ist ein guter Kandidat für strukturierende Rückschau. Aber:
- die Quellenrolle der Spur und die Rolle des rekonstruierenden Sprechers kollidieren;
- ein eigener Ausdruck für „Vorgang als Gegenstand der Rekonstruktion“ fehlt;
- die Argumentstruktur zusammengesetzter Vektorprädikate ist nicht kanonisiert.

**Ergebnis:** semantischer Kern vorhanden, syntaktische Provenienzstruktur fehlt.

---

## 3. „Sie berichtet mir ihre Rekonstruktion.“

### Kandidat
```
Tra-om bi'ku-i la'sa-i
```

würde lediglich bedeuten:
„Von ihr geht eine stimmige Weitergabe zu mir.“

Um **den Inhalt** „ihre Rekonstruktion“ zu markieren, fehlt eine dokumentierte Komplement-/Inhaltsstruktur.

### Bewertung
**C**

`Tra` trägt Weitergabe hervorragend. Aber Mishkenaz R1 dokumentiert bisher nur Quelle und Ziel, nicht:
- Inhalt einer Mitteilung,
- zitierte Proposition,
- eingebettete Behauptung,
- Besitz/Urheberschaft einer Rekonstruktion.

**Ergebnis:** Provenienz als Quelle/Ziel ist vorhanden; propositionale Einbettung fehlt.

---

## 4. „Die Rekonstruktion ist für mich stimmig, könnte aber falsch sein.“

Der erste Teil wäre grundsätzlich ausdrückbar: Eine rekonstruierende Handlung könnte `-om` tragen.

Der zweite Teil ist absichtlich **nicht** durch `-ath` auszudrücken, denn:

```
-om != wahr
-ath != falsch
-il != unbekannt
```

### Bewertung
**C — produktive Lücke**

Mishkenaz besitzt derzeit keinen eindeutig dokumentierten Marker für:
- Wahrheit,
- Falschheit,
- Wahrscheinlichkeit,
- epistemische Unsicherheit bezüglich des Wahrheitswerts.

Das ist kein Fehler des Aspektsystems, sondern bestätigt dessen saubere Trennung von relationaler Passung und Wahrheit.

**Ergebnis:** Ein eigener Wahrheits-/Behauptungsbereich ist tatsächlich nötig — mindestens lexikalisch oder syntaktisch, nicht notwendigerweise morphologisch.

---

## 5. „Zwei Modelle erklären dieselbe Spur unterschiedlich.“

### Kandidatenkern
```
Log ... Res
Log ... Res
Ta
```

`Log` kann strukturierte Modellbildung tragen, `Res` die gemeinsame Spur und `Ta` die Differenz.

Aber R1 besitzt bisher keine belastbare Konstruktion für:
- zwei Propositionen über denselben Referenten,
- Vergleich zweier Modelle,
- Koreferenz „dieselbe Spur“,
- explizite Nichtidentität der Erklärung.

### Bewertung
**C**

**Ergebnis:** Die semantischen Primitive sind vorhanden, die Vergleichs-/Koreferenzsyntax nicht.

---

## 6. „Eine Möglichkeit wurde eingeschränkt, aber nicht festgelegt.“

Das ist der entscheidende Modaltest.

Vorhanden sind:
- `Avi` — ungerichtetes Potenzial;
- `La` — Öffnung/Möglichkeitsraum;
- `Ta` — Grenze/Differenz;
- `Lim` — Schwelle;
- `-ira/-vya` — Attraktion/Distanzierung;
- `Vol` — Instabilität.

Keiner dieser Vektoren bedeutet eindeutig:
„Die Menge realisierbarer Fortsetzungen wurde kleiner, ohne auf genau eine Fortsetzung zu kollabieren.“

### Bewertung
**C — echte modale Lücke**

**Ergebnis:** Genau hier fehlt derzeit die präzise Sprache für **Einschränkung ohne Bestimmung**. Das ist wahrscheinlich die wichtigste offene Funktion der neuen Architektur.

---

## 7. „Zwei Systeme wirken aufeinander, ohne zu einem System zu verschmelzen.“

Hier ist das bestehende System überraschend stark.

### Kandidatenkern
```
Ma'Ta'U
```

trägt bereits:
„Bindung/Relation bei erhaltener Differenz.“

Mit `-reso` lässt sich zusätzlich Wechselwirkung markieren, während `-kora` gerade **nicht** gesetzt wird.

Eine mögliche strukturelle Lesart wäre:

```
Ma'Ta'U-reso
```

= „relationale Wechselwirkung unter erhaltener Differenz“

### Bewertung
**B bis A**

Die genaue morphologische Zulässigkeit von `-reso` an dieser Form muss geprüft werden, aber semantisch ist der Ausdruck sehr stark.

**Ergebnis:** Für den Kern der Kontrakosmologie brauchen wir wahrscheinlich **keinen neuen Grundvektor**. Die vorhandene Kombination `Ma + Ta + Reso` kann Koexistenz in Wechselwirkung tragen; Nicht-Integration ergibt sich aus der bewahrten Differenz und der Abwesenheit von `-kora`.

# Gesamtergebnis

| Test | Status | Hauptbefund |
|---|---|---|
| Spur wahrnehmen | B | Saha + Res reicht fast |
| aus Spur rekonstruieren | B/C | Ref + Log vorhanden; Argumentstruktur fehlt |
| Rekonstruktion berichten | C | Tra vorhanden; Inhalts-/Komplementsyntax fehlt |
| stimmig aber falsch | C | Wahrheit/Falschheit fehlen bewusst vom Aspektsystem |
| zwei Modelle, eine Spur | C | Primitive vorhanden; Vergleich/Koreferenz fehlt |
| eingeschränkt, nicht bestimmt | C | echte modale Lücke |
| Wechselwirkung ohne Verschmelzung | B/A | Ma'Ta'U + Reso sehr stark |

## Konsequenz

Die neue Architektur erfordert **nicht** pauschal neue Evidentiale oder einen neuen Vektorblock.

Es zeichnen sich stattdessen drei gezielte Entwicklungsfelder ab:

1. **Komplement- und Provenienzsyntax**  
   Wie wird der Inhalt einer Wahrnehmung, Rekonstruktion, Behauptung oder Weitergabe eingebettet?

2. **Wahrheits-/Behauptungslexik**  
   Wie unterscheidet Mishkenaz „behauptet“, „wahr“, „falsch“, „ungeprüft“, ohne diese Kategorien mit `-om/-ath/-il` zu vermischen?

3. **Modaloperator für Einschränkung ohne Festlegung**  
   Wie wird ausgedrückt, dass Möglichkeiten real eingeschränkt werden, ohne dass genau eine Fortsetzung bestimmt ist?

Diese drei Felder sollten getrennt entwickelt werden. Insbesondere darf der dritte Punkt nicht vorschnell durch `Lim` besetzt werden: `Lim` ist im bisherigen Kanon eine Schwelle, nicht bereits ein Operator auf Möglichkeitsmengen.
