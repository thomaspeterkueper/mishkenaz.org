# Mishkenaz — Bestimmung, Modalität und Erkenntnis

**Stand:** 2026-10-07  
**Scope:** Spracharchitektur / Grammatik / Vektorsystem  
**Status:** kanonische Arbeitsgrenze; konkrete Morphologie offen

## Ausgangspunkt

Die jüngste Arbeit an Omnizedenz, Kontrakosmologie und AVI macht eine Trennung nötig, die Mishkenaz bisher nur teilweise ausdrückt. Drei Fragen dürfen nicht zusammenfallen:

1. Was geschieht wirklich?
2. Wie stark sind mögliche Fortsetzungen eingeschränkt oder festgelegt?
3. Wie wissen oder behaupten wir etwas darüber?

Die Resonanzaspekte `-om/-ath/-il` beantworten keine dieser Fragen vollständig. Sie markieren die wahrgenommene relationale Passung eines Vorgangs.

## 1. Fünf orthogonale Achsen

### A. Vollzug / Wirklichkeit
Beschreibt Vorgänge, Zustände, Relationen und Aktualisierungen.

### B. Modalität / Bestimmung
Beschreibt die Struktur realisierbarer Fortsetzungen.

Vorläufig zu unterscheiden:
- Potenzial;
- Ermöglichung;
- Einschränkung;
- Bestimmung;
- Stabilisierung;
- Verlust bzw. Ausschluss.

**Arbeitsdefinition:** Bestimmung ist enger als Bedingungswirkung. Sie bezeichnet vorläufig das Festwerden einer zuvor nicht festliegenden Unterscheidung. Diese Definition bleibt prüfpflichtig.

### C. Erkenntnis
Beschreibt den Weg von wirklichem Geschehen zu Aussagen:
- mögliche Spur;
- Beobachtung;
- Rekonstruktion;
- Bericht;
- Behauptung;
- Wahrheitsprüfung.

Eine Spur ist keine Aussage. Eine Rekonstruktion kann falsch sein. Eine Behauptung kann wahr sein, obwohl ihre Begründung schlecht ist.

### D. Relationale Passung
`-om/-ath/-il` markieren, wie ein Sprecher die Passung eines Vorgangs in einer konkreten Relation wahrnimmt und mitteilt.

Daraus folgt ausdrücklich:

```
STIMMIGKEIT != WAHRHEIT
OFFENHEIT(-il) != ONTOLOGISCHE UNBESTIMMTHEIT
DISSONANZ(-ath) != FALSCHHEIT
```

### E. Referenz / Provenienz
AVI macht sichtbar, dass Größen und Aussagen an Referenzen gebunden sein können. Für Mishkenaz ist deshalb zu prüfen, wie Bezugssystem, Instrument, Quelle, Modell oder Kontext markiert werden können.

Noch keine Form ist kanonisiert.

## 2. Avi

`V00 Avi` bleibt:

> Nullpunkt / ungerichtetes Potenzial vor ausgeformter Richtung.

Avi bedeutet nicht:
- Negation;
- Vergangenheit;
- Nichtwissen;
- falsche Aussage;
- notwendige ontologische Unbestimmtheit.

Die Frage, ob ein Avi-Zustand mehrere realisierbare Fortsetzungen besitzt, ist eine zusätzliche modale Aussage und nicht bereits durch `Avi` entschieden.

## 3. Bestimmung und Spur

Die frühere lineare Lesart

```
Relation -> Wechselwirkung -> Bestimmung -> Spur
```

ist zu stark.

Arbeitsmodell:

```
Relation
  -> Wechselwirkung / Bedingungswirkung
       -> Ermöglichung
       -> Einschränkung
       -> Bestimmung
       -> Stabilisierung
       -> Verlust
```

Spuren bilden eine andere Achse:

```
wirkliches Geschehen
  -> mögliche Spur
  -> mögliche Beobachtung
  -> mögliche Rekonstruktion
  -> Behauptung
  -> Wahrheitsprüfung
```

Kein Pfeil behauptet Notwendigkeit.

## 4. Vektoren: Prüfmatrix

Noch keine Umdeutung ist kanonisiert. Folgende Kandidaten sollen gezielt geprüft werden:

| Vektor/Form | heutiger Kern | neue Prüffrage |
|---|---|---|
| Avi | Nullpunkt / Potenzial | Potenzial ohne Behauptung ontologischer Offenheit |
| Lim | Schwelle / Grenze | Einschränkung eines Möglichkeitsraums? |
| Abs | Abzug / Trennung | Ausschluss oder Verlust von Fortsetzungen? |
| Ref | Rückbezug | Referenzierung statt epistemischer Gewissheit? |
| Rek | Rückkopplung / Rekonstruktion | eignet sich eine historische Lesart für Rekonstruktion? |
| Log | Ordnung / Muster | Stabilisierung bzw. explizite Modellbildung? |
| Ori | Rekursion mit Gedächtnis | Fortsetzung unter historisch veränderten Bedingungen |
| Ta | Differenz | Voraussetzung unterscheidbarer Alternativen / Pole |

Diese Tabelle ist eine Prüfagenda, keine neue Vektordefinition.

## 5. Kontrakosmologische Konsequenz

Mishkenaz benötigt möglicherweise eine Konstruktion für **Koexistenz ohne Synthese**:

```
A || B
```

Gemeinsamer Vollzug oder gemeinsamer Raum bedeutet dabei nicht:
- Identität;
- Harmonisierung;
- Auflösung der Differenz;
- gemeinsamen Wahrheitswert.

`Ma'Ta'U` ist hierfür ein wichtiger vorhandener Kandidat, reicht aber möglicherweise nicht für inkommensurable Referenzrahmen. Vor Einführung einer neuen Form ist zu prüfen, ob Syntax oder vorhandene Meta-Operatoren genügen.

## 6. Entwicklungsregel

Neue Morpheme werden erst eingeführt, wenn:

1. die semantische Funktion eindeutig abgegrenzt ist;
2. vorhandene Vektoren und Syntax die Funktion nicht bereits tragen;
3. Proto-Mishkenaz eine plausible lautliche/historische Ableitung erlaubt;
4. die Form nicht nur Omnizedenz, AVI oder Kontrakosmologie kodiert, sondern allgemein sprachlich verwendbar ist;
5. die Sprache auch gegenteilige Aussagen ausdrücken kann.

Insbesondere muss Mishkenaz Sätze ermöglichen wie:
- eine Rekonstruktion ist falsch;
- eine Behauptung ist wahr, aber relational dissonant;
- zwei Modelle bleiben inkompatibel;
- ein Vorgang ist beobachtet, aber seine Ursache unbestimmt;
- eine Möglichkeit wurde eingeschränkt, aber nicht eindeutig festgelegt.
