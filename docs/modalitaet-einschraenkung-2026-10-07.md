# Mishkenaz — Modalität: Einschränkung ohne Bestimmung

**Stand:** 2026-10-07  
**Status:** Arbeitsmodell / keine neue Form kanonisiert

## 1. Problem

Gesucht ist eine Ausdrucksform für:

> „Der reale Möglichkeitsraum ist kleiner geworden, aber mehr als eine Fortsetzung bleibt realisierbar.“

Das ist weder:
- bloße Offenheit;
- bloße Grenze;
- bloße Instabilität;
- vollständige Bestimmung;
- noch epistemisches Nichtwissen.

## 2. Formale Arbeitsdefinition

Sei `M(t)` die Menge realisierbarer Fortsetzungen unter den aktuellen Bedingungen.

Dann bedeutet **Einschränkung**:

```
M(t+1) ⊂ M(t)
```

und **noch keine vollständige Bestimmung**:

```
|M(t+1)| > 1
```

Bestimmung im starken Sinn wäre dagegen näher an:

```
|M(t+1)| = 1
```

Diese Mengenform ist nur metasprachliche Präzisierung, keine Behauptung, dass Mishkenaz selbst Mengenlehre kodiert.

## 3. Vorhandene Vektoren und ihre Grenzen

### Avi
Potenzial vor ausgeformter Richtung. Kein Marker für die Größe eines Möglichkeitsraums.

### La
Öffnung / Raum / Ermöglichung. Gut für das Vorhandensein von Möglichkeiten, aber nicht für deren Reduktion.

### Ta
Grenze / Differenz. Kann eine Unterscheidung oder einen Rand setzen, sagt aber nicht, wie viele Fortsetzungen verbleiben.

### Lim
Schwelle / Grenze als Ort. Kann Bedingungen eines Übergangs markieren, ist aber kein Operator „Möglichkeiten reduzieren“.

### -ira / -vya
Anziehung / Distanzierung. Können Fortsetzungen wahrscheinlicher oder weniger zugänglich machen, ohne sie notwendig auszuschließen.

### Vol
Instabilität. Beschreibt geringe Stabilität, nicht Einschränkung.

### Sa / Sa-h / -h
Bruch / Auflösung / Loslassen. Können Möglichkeiten vernichten, aber nicht allgemein und nicht notwendigerweise kontrolliert.

## 4. Konsequenz

Der bestehende Vektorraum beschreibt **Struktur und Dynamik von Möglichkeiten**, aber nicht explizit die Operation:

```
mehrere Möglichkeiten -> weniger Möglichkeiten
```

ohne vollständige Festlegung.

Das ist eine reale semantische Lücke.

## 5. Bevorzugte Lösung

Die Lücke sollte zunächst **nicht** mit einem neuen Grundvektor gefüllt werden.

Stattdessen sind zwei Wege zu testen:

### A. Resultative Konstruktion
Einschränkung als Ergebnis einer Relation ausdrücken:

```
[Wechselwirkung] -> [La-Raum] + [Ta/Lim-Grenze] -> kleinerer Fortsetzungsraum
```

Vorteil:
- kein neuer primitiver Begriff;
- Bestimmung bleibt kompositional.

Nachteil:
- „kleiner“ ist noch nicht grammatisch kodiert.

### B. Skalarer Operator
Falls nötig, könnte später der bereits offene **INTENS-Slot** nicht nur Intensität, sondern gerichtete Skalierung tragen.

Dann wäre formal etwas wie:

```
REDUKTION(La)
```

denkbar: weniger offener Raum, ohne Null oder Eins festzulegen.

Das wäre architektonisch attraktiver als ein neuer Vektor, weil Einschränkung eine **Operation auf einem Möglichkeitsraum** ist, nicht notwendig ein eigener Weltbestandteil.

## 6. Verbindung zum bestehenden INTENS-Slot

Der bisher offene Slot:

```
(NEG) — (INTENS) — STAMM — ...
```

könnte sich als allgemeiner **Skalierungs-/Grad-Slot** erweisen.

Dann könnte er nicht nur „stärker/schwächer“ ausdrücken, sondern bei geeigneten Stämmen:
- mehr/weniger offen;
- stärker/schwächer gebunden;
- größer/kleinerer Spielraum;
- höhere/niedrigere Stabilität.

Das wäre mit `Ska` (Skalierung/Muster) semantisch anschlussfähig, ohne `Ska` automatisch zu einem Grammatikmorphem zu machen.

## 7. Bestimmung

Bestimmung sollte vorerst **kein eigener Marker** sein.

Arbeitsannahme:

> Bestimmung ist ein resultatives Verhältnis, bei dem relevante Alternativen nicht mehr realisierbar sind.

Damit wäre Bestimmung grammatisch eher eine Aussage über den Zustand eines Möglichkeitsraums als eine elementare Operation.

## 8. Nächster Test

Zu testen sind Kontraste wie:

1. „Viele Wege sind offen.“
2. „Weniger Wege sind offen.“
3. „Nur noch ein Weg ist offen.“
4. „Kein Weg ist offen.“
5. „Ich weiß nicht, wie viele Wege offen sind.“

Wenn Mishkenaz diese fünf Sätze sauber unterscheiden kann, sind Modalität und Erkenntnis hinreichend getrennt.
