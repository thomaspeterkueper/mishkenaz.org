# Mishkenaz — Referenz, Namen, Dinge und gesprochene Struktur

**Stand:** 2026-10-09  
**Status:** Arbeitsmodell / Grundlage für R1-Nominal- und Prosodiesystem

## 1. Warum diese Schicht fehlt

Die bisherige Grammatik beschreibt vor allem Vollzug, Relation und semantische Operationen.

Für vollständige Sprache braucht Mishkenaz zusätzlich eine Referenzschicht:

```
PRÄDIKAT
-> ROLLEN
-> REFERENTEN
```

Referenten können mindestens sein:

- konkrete Personen;
- Eigennamen;
- Dinge;
- Orte;
- Gruppen;
- abstrakte Gegenstände;
- bereits eingeführte Diskursreferenten.

Diese Ebene darf nicht mit den Vektortypen verwechselt werden.

```
SYS != Nomen
REL != Präposition
NAME != semantischer Typ
```

## 2. Grundprinzip

R1 bleibt vorgangsorientiert:

```
PREDIKAT — bi'QUELLE — la'ZIEL / GEGENÜBER
```

Die Nominalphrase steht nicht im Zentrum des Satzes, sondern identifiziert den jeweiligen Teilnehmer.

Beispiel in analytischer Form:

```
Saha-om bi'[PERSON: Daria] la'[THING: Bach]
```

Die eckigen Klammern sind Metanotation, keine R1-Orthographie.

## 3. Vier Referenzklassen

### A. Eigenname

Ein Eigenname identifiziert einen diskursiv angenommenen individuellen Referenten:

```
Daria
Varuna
Dvārakā
```

Der Name trägt zunächst keine automatische ontologische Beschreibung.

```
Daria != PERSON-MORPHEM
Dvārakā != ORT-MORPHEM
```

Ob ein Referent Person, Ort oder anderes ist, folgt aus Lexikon, Weltwissen und Kontext.

### B. Gattungs-/Klassenbezeichnung

Beispiele:

```
Kind
Stein
Baum
Haus
Fluss
```

Sie benennen eine Klasse oder Eigenschaft, nicht automatisch einen eindeutigen Einzelreferenten.

### C. Deiktischer / anaphorischer Referent

Ein bereits bekannter oder situativ bestimmter Referent kann durch Pronomen, Demonstration oder spätere reduzierte Formen aufgenommen werden.

Die vorhandenen Formen `sa`, `ta`, `ku` gehören in diese Schicht, ohne das gesamte Nominalsystem zu ersetzen.

### D. Relational bestimmter Referent

Ein Referent kann durch seine Beziehung identifiziert werden:

```
das Haus am Fluss
die Mutter des Kindes
der Stein in der Mauer
```

R1 sollte solche Bestimmungen bevorzugt relational statt durch schwere Nominalflexion ausdrücken.

## 4. Namen in Rollen

Rollenmarker binden an die gesamte Referenzphrase:

```
bi'Daria
la'Varuna
bi'Dvārakā
```

Arbeitsregel:

> `bi'` und `la'` verändern nicht den Namen; sie markieren seine Rolle im Vollzug.

Damit bleibt der Name zitier- und wiedererkennbar.

## 5. Dinge und Klassen

Für Dinge sollte R1 zunächst keine unnötigen Kategorien wie grammatisches Genus oder obligatorische Artikel einführen.

Minimalmodell:

```
LEXEM
LEXEM + Quantifikation
LEXEM + relationale Bestimmung
```

Beispiel:

```
Stein
Stein-mira
Stein-ona
```

nur falls die Produktivität von `-mira/-ona` außerhalb des Pronominalsystems bestätigt wird.

Bis dahin gilt:

> Zahl und Kollektivität nicht stillschweigend am Nomen grammatikalisieren.

## 6. Definiertheit

R1 braucht nicht zwingend sofort einen Artikel wie „der/die/das“.

Definiertheit kann zunächst aus drei Quellen entstehen:

1. Eigenname;
2. Deixis / Pronomen;
3. Diskursstatus und relationale Bestimmung.

Beispiel:

```
la'[Haus bi'Varuna]
```

analytisch:

> das Haus, dessen Quelle/Besitz-/Zuordnungsrelation zu Varuna im Kontext relevant ist.

Die genaue Possessivsyntax bleibt zu rekonstruieren; dieses Beispiel ist keine fertige R1-Form.

## 7. Gesprochene Struktur

Gesprochene R1-Sprache muss mindestens vier Grenzen hörbar machen:

1. Prädikatskern;
2. Rollenmarker;
3. Referenzphrase;
4. Klauselgrenze.

Arbeitsannahme:

```
[PREDIKAT] | [bi' REFERENT] | [la' REFERENT]
```

mit kleinen prosodischen Gruppen statt Wort-für-Wort-Isolation.

## 8. Prosodische Hierarchie

Vorläufige Hierarchie:

```
ÄUSSERUNG
  -> KLAUSEL
    -> PRÄDIKATSGRUPPE
    -> ROLLENGRUPPE(N)
      -> REFERENZPHRASE
```

Das erlaubt, komplexe Vektorkerne und komplexe Namen hörbar zu unterscheiden.

## 9. Betonung

Solange das historische Phoneminventar noch nicht vollständig rekonstruiert ist, wird keine starre Silbenbetonungsregel erfunden.

Stattdessen gilt als sichere prosodische Arbeitsregel:

> Jede prosodische Gruppe besitzt einen Hauptakzent; Rollenmarker sind schwächer als der lexikalische Kern ihres Referenten.

Also ungefähr:

```
bi' DARIA
la' VARUNA
```

nicht:

```
BI' daria
LA' varuna
```

Dies ist eine relative Akzentregel, noch keine Aussage über exakte Silbenbetonung.

## 10. Eigennamen und Lautsystem

Eigennamen können drei Herkunftsklassen besitzen:

### A. interne Mishkenaz-Namen

Sie müssen vollständig den phonotaktischen Regeln der jeweiligen Sprachstufe folgen.

### B. historisch übernommene Namen

Sie werden an die Lautstruktur angepasst, können aber konservative Merkmale bewahren.

### C. fremde / moderne Namen

Sie können als Lehnnamen erscheinen.

Für sie braucht R1 langfristig Regeln für:

- nicht vorhandene Laute;
- Konsonantencluster;
- Silbenstruktur;
- Akzentanpassung;
- mögliche Epenthese;
- Flexions-/Rollenanschluss.

Bis das Phoneminventar vollständig ist, dürfen keine konkreten Lautanpassungsregeln erfunden werden.

## 11. Namen sind semantisch opak

Ein besonders wichtiges Prinzip:

> Die lautliche Form eines Namens zwingt nicht automatisch seine Bedeutung.

Wenn eine Person etwa `Ma...` im Namen trägt, folgt daraus nicht, dass sie ontologisch „Bindung“ ist.

Historische Namensbildung kann Vektoren verwenden, aber synchron kann ein Name lexikalisiert und semantisch opak sein.

```
ETYMOLOGIE != AKTUELLE REFERENZ
```

Das schützt Mishkenaz vor übermäßiger symbolischer Determination.

## 12. Dinge sind keine isolierten Substanzen

Die prozess-relationale Grundhaltung darf trotzdem sichtbar bleiben:

Ein Dinglexem identifiziert eine relativ stabile Formation, ohne zu behaupten, dass sie unabhängig von Relationen existiert.

Analytisch:

```
THING-LEXEM -> Referent
Referent kann semantisch als SYS modelliert werden
```

aber:

```
THING-LEXEM != SYS
```

Das ist die wichtige Schnittstelle zwischen Grammatik und Vektoralgebra.

## 13. Orte

Orte können als Referenten oder als relationale Räume auftreten.

Beispiel:

```
Dvārakā
```

kann als individueller Ort referieren.

`La` als Vektor bezeichnet dagegen Öffnung / zugänglichen Raum und ist nicht einfach ein Lokativ.

Daher:

```
ORTSNAME != SPACE
```

Ein Ortsreferent kann aber in einer semantischen Analyse als `SYS`, `SPACE` oder komplexe Formation modelliert werden, je nach Vollzug.

## 14. Schnittstelle zur Vektoralgebra

Wir brauchen künftig eine explizite Abbildung:

```
REFERENZAUSDRUCK
-> DISKURSREFERENT
-> SEMANTISCHER TYP IM AKTUELLEN VOLLZUG
```

Beispiel:

```
Daria
-> individueller Referent d1
-> SYS in Ma(d1,d2)
```

Der semantische Typ hängt also nicht allein vom Lexem ab, sondern von seiner Funktion in der aktuellen Operation.

## 15. Konsequenz für den Validator

Der bisherige Validator prüft semantische Vektortypen.

Der nächste Ausbau sollte eine Referenzschicht ergänzen:

```
Name: Daria      -> REF#daria
Klasse: Stein    -> CLASS#stein
Ort: Dvārakā     -> REF#dvaraka
```

und erst im jeweiligen Ausdruck zuordnen:

```
REF#daria : SYS
REF#dvaraka : SYS/SPACE (kontextabhängig)
```

Damit kann später ein vollständiger Satz statt nur ein Vektorkern validiert werden.

## 16. Offene Fragen

- Phoneminventar und Silbenstruktur von R1;
- genaue Wortakzentregeln;
- prosodische Markierung enger Operatorbindung;
- Definitheit ohne obligatorischen Artikel;
- Possession und Genitivrelation;
- Adjektiv-/Eigenschaftsmodifikation;
- Ortsrelationen;
- Namensanpassung bei Sprachkontakt;
- Produktivität von `-mira/-ona` bei Nomen;
- Eigennamenbildung aus Vektoren versus semantisch opake Namen.
